# Recetario Interactivo

Aplicación web que permite crear, editar, eliminar y visualizar recetas de cocina.  
Cada receta se guarda en localStorage, por lo que se conserva al recargar la página.

## ✨ Características

- Formulario para agregar recetas con título, país, ingredientes, categoría y pasos.
- Las recetas se muestran en tarjetas con diseño personalizado por país.
- Funcionalidad para eliminar y editar recetas.
- Búsqueda de recetas por nombre.
- Persistencia de datos con localStorage.
- Diseño responsive (en progreso).

## 🛠️ Tecnologías

- HTML5  
- CSS3  
- JavaScript (ES6)
